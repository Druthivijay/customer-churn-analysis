## Project Overview
Analysis of telecom customer churn using Python and Power BI.

## Dataset
- 7043 customers, 21 features
- Source: IBM Watson Telco Customer Churn Dataset

## Tools Used
- Python (Pandas, Seaborn, Scikit-learn)
- Power BI

## Key Findings
- Churn Rate: 26.54%
- Month-to-month contract customers churn the most
- Churned customers pay higher monthly charges
- Logistic Regression Accuracy: ~81%

## Files
- `churn_analysis.ipynb` - Main analysis notebook
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` - Dataset
- `dashboard_screenshot.png` - Power BI Dashboard
